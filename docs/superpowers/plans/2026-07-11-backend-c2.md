# Fase C-2 — Backend "panadería" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `backend/` — a local FastAPI service that turns `citygen` (Fase C-1) into a shared "bakery": players request a zone (point + size), a single worker thread generates it once via `citygen.generate`, and it's served from disk forever after. Implements the 5 endpoints of contract 4 (ESPEC_SESION_CIUDADES2), SQLite-backed state, and daily generation quotas.

**Architecture:** `store.py` (SQLite CRUD, no business logic) → `quotas.py` (daily-limit logic built on `store.py`) → `worker.py` (single background thread draining a `queued` FIFO, calling `citygen.generate`, persisting results via `store.py`) → `app.py` (FastAPI routes wiring all of the above + a Nominatim geocode proxy). `uvicorn app:app` run from inside `backend/` starts everything (DB init, storage dirs, worker thread) via a FastAPI lifespan handler.

**Tech Stack:** Python 3.10+, `fastapi` + `uvicorn` (new, backend-only deps — explicitly allowed), `requests` (already required transitively by `citygen`, reused directly by `app.py` for the Nominatim call), `sqlite3` (stdlib). `unittest` (stdlib) for `store.py`/`quotas.py`/`worker.py` — no pytest, matching `data_pipeline` convention.

## Global Constraints

- `backend/` may add **only** `fastapi` and `uvicorn` as new dependencies (rule 5 of the spec). `requests` is not "new" — `citygen` already requires it; `app.py` reusing it for the Nominatim call adds nothing to the dependency surface.
- **No `httpx`.** FastAPI's `TestClient` needs `httpx` in this Starlette version, which would be an unlisted new dependency. So `app.py`'s HTTP layer is **not** covered by automated tests — it's verified with the exact `curl` commands the spec itself asks for (item 4 of Fase C-2: "Proveer ... los comandos curl exactos del flujo completo"). `store.py`, `quotas.py`, and `worker.py` (pure Python + SQLite, no HTTP) get full TDD coverage.
- One implementation of generation logic: `backend/` never re-implements anything from `citygen/`; it only calls `citygen.generate`. No logic is ported to GDScript or duplicated.
- Concurrency of generation = 1: a single background thread drains the queue, FIFO.
- Quotas: 3 cold generations/day UTC per `X-Client-Id` **and** per IP — whichever is more restrictive blocks the request. Downloads of `ready` zones never consume quota (the code path for downloads never calls `quotas.check_and_increment`).
- `failed` zones store an exact machine-readable `reason`: the contract-3 causes (`insufficient_road_data`, `fragmented_road_graph`, `zone_too_dense`) plus `osm_unavailable` / `elevation_unavailable` for environmental failures.
- State in SQLite (`store.py`); generated files at `backend/storage/zones/<zone_id>/map.json`. Both live under `backend/storage/`, which is fully gitignored (DB + raw citygen cache + served files — all runtime state, nothing to commit).
- `backend/` is a flat script directory (no `__init__.py`), matching how it's meant to run: `cd backend && uvicorn app:app`. Modules import each other as plain siblings (`import store`, not `from . import store`).
- `citygen` is imported via a `sys.path` insert pointing at `data_pipeline/` (no installable package exists yet; this mirrors how `generate_map.py` itself sits next to `citygen/`).

### API contract (v1, from ESPEC_SESION_CIUDADES2 §4 — reproduced here so no task needs to re-derive it)

| Endpoint | Behavior |
|---|---|
| `GET /v1/geocode?q=<texto>` | Cached proxy to Nominatim (`format=json&limit=5`, identifiable `User-Agent`, global 1 req/s throttle). Returns up to 5 `{name, lat, lon}`. |
| `POST /v1/zones` body `{lat, lon, size, name?}` | Canonicalizes via `citygen.zones.resolve`. If a row for that `zone_id` already exists (any status): return its current status, never re-enqueue. Else: quota check → `429 {reason:"quota", resets_at}` if exceeded, else insert as `queued` and return `{zone_id, status:"queued", queue_position}`. |
| `GET /v1/zones/{zone_id}` | `{status, stage?, queue_position?, reason?, meta_summary?}`. `stage ∈ {osm, elevation, build, package}`. `meta_summary` (only if `ready`) = `{name, zone_size, stats}`. |
| `GET /v1/zones/{zone_id}/map.json` | The generated file (contains its own license/attribution in `meta`, unchanged from `citygen`). |
| `GET /v1/catalog` | `[{zone_id, name, zone_size, flags}]` for every `ready` zone. |

**Two decisions the spec left implicit, resolved here (simplest option per rule 7, both flagged inline in the code with `# DECISION_PENDIENTE`):**
1. The POST body contract literally reads `{lat, lon, size}` with no `name`, but `citygen` needs a display name for `meta.name`. The natural source is the name the player already picked in the geocode step (Fase C-3's `CityPanel`). So `name` is accepted as an **optional additive field**; if absent, falls back to `"{lat:.4f}, {lon:.4f}"`.
2. "Si existe" (contract 4, POST row) is written as if there were only two states (ready / not-yet-created), but a second player can race a first player's in-flight `queued`/`generating`/`failed` row. Simplest rule that satisfies every checklist item: **any existing row, in any status, is returned as-is and never re-enqueued.** A `failed` zone is not auto-retried in this phase (no checklist item exercises retry; a human can delete the row manually if ever needed).

## Interfaces summary (for cross-task reference)

- `store.init_db(db_path)` — creates tables if missing; requeues any `generating` row back to `queued` (crash recovery).
- `store.insert_zone_queued(db_path, zone_id, lat, lon, size, name)`
- `store.get_zone(db_path, zone_id) -> dict|None` (columns: `zone_id, status, stage, reason, lat, lon, size, name, created_at, meta_summary_json`)
- `store.get_queue_position(db_path, zone_id) -> int` (1-indexed, FIFO by SQLite `rowid`)
- `store.next_queued_zone(db_path) -> dict|None`
- `store.update_zone_stage(db_path, zone_id, stage)` — also flips status to `generating`
- `store.mark_zone_ready(db_path, zone_id, meta_summary: dict)`
- `store.mark_zone_failed(db_path, zone_id, reason: str)`
- `store.list_catalog(db_path) -> list[dict]`
- `store.get_quota_count(db_path, kind, identifier, date) -> int`; `store.increment_quota(db_path, kind, identifier, date)`
- `store.get_geocode_cache(db_path, query) -> list|None`; `store.save_geocode_cache(db_path, query, results)`
- `quotas.check_and_increment(db_path, client_id, ip) -> {"allowed": bool, "resets_at": str|None}`
- `worker._process_zone(db_path, cache_dir, zones_dir, row: dict)` — one zone, synchronous
- `worker.run_forever(db_path, cache_dir, zones_dir, stop_event: threading.Event)`
- `worker.start_background_thread(db_path, cache_dir, zones_dir) -> threading.Thread`

```python
#!/usr/bin/env python3
"""Persistencia SQLite del backend: estado de zonas, cuotas diarias y cache
de geocodificacion. Sin logica de negocio (eso vive en quotas.py/worker.py) --
solo CRUD."""
import json
import sqlite3
from datetime import datetime, timezone


def _connect(db_path: str) -> sqlite3.Connection:
    conn = sqlite3.connect(db_path, timeout=10)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA journal_mode=WAL")
    return conn


def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")


def init_db(db_path: str) -> None:
    conn = _connect(db_path)
    try:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS zones (
                zone_id TEXT PRIMARY KEY,
                status TEXT NOT NULL,
                stage TEXT,
                reason TEXT,
                lat REAL,
                lon REAL,
                size TEXT,
                name TEXT,
                created_at TEXT NOT NULL,
                meta_summary_json TEXT
            )
        """)
        conn.execute("""
            CREATE TABLE IF NOT EXISTS quotas (
                kind TEXT NOT NULL,
                identifier TEXT NOT NULL,
                date TEXT NOT NULL,
                count INTEGER NOT NULL DEFAULT 0,
                PRIMARY KEY (kind, identifier, date)
            )
        """)
        conn.execute("""
            CREATE TABLE IF NOT EXISTS geocode_cache (
                query TEXT PRIMARY KEY,
                results_json TEXT NOT NULL,
                cached_at TEXT NOT NULL
            )
        """)
        conn.commit()
        # Recuperacion de caidas: un proceso que muere a mitad de generar deja
        # una zona "generating" huerfana para siempre si nadie la re-encola.
        conn.execute("UPDATE zones SET status = 'queued', stage = NULL WHERE status = 'generating'")
        conn.commit()
    finally:
        conn.close()


def insert_zone_queued(db_path: str, zone_id: str, lat: float, lon: float, size: str, name: str) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "INSERT INTO zones (zone_id, status, stage, reason, lat, lon, size, name, created_at, meta_summary_json) "
            "VALUES (?, 'queued', NULL, NULL, ?, ?, ?, ?, ?, NULL)",
            (zone_id, lat, lon, size, name, _now()),
        )
        conn.commit()
    finally:
        conn.close()


def get_zone(db_path: str, zone_id: str):
    conn = _connect(db_path)
    try:
        row = conn.execute("SELECT * FROM zones WHERE zone_id = ?", (zone_id,)).fetchone()
        return dict(row) if row is not None else None
    finally:
        conn.close()


def get_queue_position(db_path: str, zone_id: str) -> int:
    """1-indexado, FIFO por orden de insercion real (rowid), no por timestamp
    (evita empates cuando dos zonas se encolan dentro del mismo segundo)."""
    conn = _connect(db_path)
    try:
        row = conn.execute(
            "SELECT COUNT(*) AS n FROM zones WHERE status = 'queued' "
            "AND rowid <= (SELECT rowid FROM zones WHERE zone_id = ?)",
            (zone_id,),
        ).fetchone()
        return row["n"]
    finally:
        conn.close()


def next_queued_zone(db_path: str):
    conn = _connect(db_path)
    try:
        row = conn.execute(
            "SELECT * FROM zones WHERE status = 'queued' ORDER BY rowid ASC LIMIT 1"
        ).fetchone()
        return dict(row) if row is not None else None
    finally:
        conn.close()


def update_zone_stage(db_path: str, zone_id: str, stage: str) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "UPDATE zones SET status = 'generating', stage = ? WHERE zone_id = ?", (stage, zone_id)
        )
        conn.commit()
    finally:
        conn.close()


def mark_zone_ready(db_path: str, zone_id: str, meta_summary: dict) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "UPDATE zones SET status = 'ready', stage = NULL, reason = NULL, meta_summary_json = ? "
            "WHERE zone_id = ?",
            (json.dumps(meta_summary), zone_id),
        )
        conn.commit()
    finally:
        conn.close()


def mark_zone_failed(db_path: str, zone_id: str, reason: str) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "UPDATE zones SET status = 'failed', stage = NULL, reason = ? WHERE zone_id = ?",
            (reason, zone_id),
        )
        conn.commit()
    finally:
        conn.close()


def list_catalog(db_path: str) -> list:
    conn = _connect(db_path)
    try:
        rows = conn.execute(
            "SELECT zone_id, name, size, meta_summary_json FROM zones WHERE status = 'ready' ORDER BY rowid ASC"
        ).fetchall()
        catalog = []
        for row in rows:
            summary = json.loads(row["meta_summary_json"])
            catalog.append({
                "zone_id": row["zone_id"],
                "name": row["name"],
                "zone_size": row["size"],
                "flags": summary["stats"]["flags"],
            })
        return catalog
    finally:
        conn.close()


def get_quota_count(db_path: str, kind: str, identifier: str, date: str) -> int:
    conn = _connect(db_path)
    try:
        row = conn.execute(
            "SELECT count FROM quotas WHERE kind = ? AND identifier = ? AND date = ?",
            (kind, identifier, date),
        ).fetchone()
        return row["count"] if row is not None else 0
    finally:
        conn.close()


def increment_quota(db_path: str, kind: str, identifier: str, date: str) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "INSERT INTO quotas (kind, identifier, date, count) VALUES (?, ?, ?, 1) "
            "ON CONFLICT(kind, identifier, date) DO UPDATE SET count = count + 1",
            (kind, identifier, date),
        )
        conn.commit()
    finally:
        conn.close()


def get_geocode_cache(db_path: str, query: str):
    conn = _connect(db_path)
    try:
        row = conn.execute(
            "SELECT results_json FROM geocode_cache WHERE query = ?", (query,)
        ).fetchone()
        return json.loads(row["results_json"]) if row is not None else None
    finally:
        conn.close()


def save_geocode_cache(db_path: str, query: str, results: list) -> None:
    conn = _connect(db_path)
    try:
        conn.execute(
            "INSERT INTO geocode_cache (query, results_json, cached_at) VALUES (?, ?, ?) "
            "ON CONFLICT(query) DO UPDATE SET results_json = excluded.results_json, cached_at = excluded.cached_at",
            (query, json.dumps(results), _now()),
        )
        conn.commit()
    finally:
        conn.close()
```

```python
#!/usr/bin/env python3
"""Cuota diaria de generaciones frias: 3/dia UTC por X-Client-Id Y por IP, la
mas restrictiva bloquea (contrato ESPEC_SESION_CIUDADES2 §4). Solo se llama al
encolar una zona NUEVA -- descargar o reconsultar una zona ya existente nunca
pasa por aqui, por lo que nunca consume cuota."""
from datetime import datetime, timedelta, timezone

import store

MAX_COLD_GENERATIONS_PER_DAY = 3


def _today_utc() -> str:
    return datetime.now(timezone.utc).strftime("%Y-%m-%d")


def _next_reset_utc() -> str:
    tomorrow = (datetime.now(timezone.utc) + timedelta(days=1)).date()
    reset = datetime(tomorrow.year, tomorrow.month, tomorrow.day, tzinfo=timezone.utc)
    return reset.isoformat(timespec="seconds").replace("+00:00", "Z")


def check_and_increment(db_path: str, client_id: str, ip: str) -> dict:
    today = _today_utc()
    client_count = store.get_quota_count(db_path, "client", client_id, today)
    ip_count = store.get_quota_count(db_path, "ip", ip, today)
    if client_count >= MAX_COLD_GENERATIONS_PER_DAY or ip_count >= MAX_COLD_GENERATIONS_PER_DAY:
        return {"allowed": False, "resets_at": _next_reset_utc()}
    store.increment_quota(db_path, "client", client_id, today)
    store.increment_quota(db_path, "ip", ip, today)
    return {"allowed": True, "resets_at": None}
```

```python
#!/usr/bin/env python3
"""Hilo unico consumidor de la cola de zonas (concurrencia global de
generacion = 1, contrato ESPEC_SESION_CIUDADES2 §4). Ejecuta citygen.generate()
y persiste el resultado via store.py. Nunca porta logica de generacion aqui --
solo orquesta la cola y el logging de transiciones de estado."""
import logging
import os
import sys
import threading
import time

sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "data_pipeline"))
from citygen import ZoneSpec, generate  # noqa: E402

import store  # noqa: E402

logger = logging.getLogger("citygen.worker")
logging.basicConfig(level=logging.INFO, format="%(asctime)s %(message)s")

POLL_INTERVAL_SECONDS = 1.0
# Solo dos categorias de fallo "ambiental" existen en el contrato ademas de las
# de validate.py; una excepcion inesperada en build/package (bug, no red) se
# reporta igual como elevation_unavailable -- no hay categoria dedicada en esta
# fase y encolar-para-siempre violaria "nunca degradar en silencio".
STAGE_FAILURE_REASON = {"osm": "osm_unavailable", "elevation": "elevation_unavailable"}


def _process_zone(db_path: str, cache_dir: str, zones_dir: str, row: dict) -> None:
    zone_id = row["zone_id"]
    zone = ZoneSpec(name=row["name"], size=row["size"], lat=row["lat"], lon=row["lon"])
    out_path = os.path.join(zones_dir, zone_id, "map.json")
    current_stage = "osm"

    def progress(stage):
        nonlocal current_stage
        current_stage = stage
        store.update_zone_stage(db_path, zone_id, stage)
        logger.info("[zone %s] -> generating(%s)", zone_id, stage)

    t0 = time.time()
    logger.info("[zone %s] queued -> generating(osm)", zone_id)
    try:
        result = generate(zone, cache_dir, out_path, progress_cb=progress)
    except Exception:
        elapsed = time.time() - t0
        reason = STAGE_FAILURE_REASON.get(current_stage, "elevation_unavailable")
        logger.exception("[zone %s] fallo inesperado en stage=%s tras %.1fs", zone_id, current_stage, elapsed)
        store.mark_zone_failed(db_path, zone_id, reason)
        return

    elapsed = time.time() - t0
    if not result.ok:
        logger.info("[zone %s] failed (%s) tras %.1fs", zone_id, result.reason, elapsed)
        store.mark_zone_failed(db_path, zone_id, result.reason)
        return

    size_bytes = result.diagnostics.get("size_bytes", 0)
    meta_summary = {"name": zone.name, "zone_size": zone.size, "stats": result.stats}
    store.mark_zone_ready(db_path, zone_id, meta_summary)
    logger.info("[zone %s] ready (%.0f s, %.1f MB)", zone_id, elapsed, size_bytes / (1024 * 1024))


def run_forever(db_path: str, cache_dir: str, zones_dir: str, stop_event: threading.Event) -> None:
    while not stop_event.is_set():
        row = store.next_queued_zone(db_path)
        if row is None:
            stop_event.wait(POLL_INTERVAL_SECONDS)
            continue
        _process_zone(db_path, cache_dir, zones_dir, row)


def start_background_thread(db_path: str, cache_dir: str, zones_dir: str) -> threading.Thread:
    stop_event = threading.Event()
    thread = threading.Thread(
        target=run_forever, args=(db_path, cache_dir, zones_dir, stop_event), daemon=True,
    )
    thread.stop_event = stop_event
    thread.start()
    return thread
```

```python
def _zone_status_response(row: dict) -> dict:
```
